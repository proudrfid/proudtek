## Description
Inkjet PVC ID cards for in-house badge printing and RFID encoding, suited to employee IDs, visitor cards, event passes and membership programs.

## Summary
- Inkjet PVC ID cards are made for organizations that want to print and personalize RFID cards in-house using compatible inkjet card printers.
- The Inkjet ID card is laminated with film which is painted with special material, it allows the end user to directly print by an inkjet printer.
- ProudTek inkjet ID card can be sinked into water, and the image on card will remain, just like the regular printed PVC card.
