# 权威度建设:90 天 15-25 个真实引用域(T2)

> 这是整个计划里唯一无法用代码代劳、但决定成败的轨道。内容与站内优化已就位,
> 外链是唯一缺口。每周固定 2-3 小时执行,按周记账。

## A. 目录与档案(第 1-2 周,低垂果实,预计 6-8 个)

| 目标 | 说明 |
|---|---|
| RFID Journal 目录 | 行业核心目录,提交公司档案 |
| Globalsources / Made-in-China 付费会员页 | 已有店铺的话确认官网链接是 dofollow |
| 深圳市物联网协会 / 行业商会会员页 | 中文权威+本地实体信号 |
| Clutch/GoodFirms 类 B2B 目录 | 「RFID manufacturer Shenzhen」条目 |
| Crunchbase / LinkedIn 公司页补全 | 实体一致性(名称/地址/电话与站内一致) |

## B. 客座/内容合作(第 2-8 周,预计 4-6 个)

- 目标:包装/活动科技/物联网/安防门禁垂直博客(DR 30-60 区间最现实)
- 素材直接用站内原创数据:腕带收入提升出处对照表、UHF 腕带真实读距研究、
  现金less ROI 算术模型——这些是别人没有的原创数据,是编辑愿意收的原因
- 每篇带 1-2 条自然链接指向对应 LP/支柱页

## C. 数据化 PR / 专家回应(第 4-10 周,预计 3-5 个)

- HARO(Connectively)/ Featured / Qwoted:以「Shenzhen RFID factory lead」
  身份回应记者关于 RFID/NFC/无现金活动的提问
- 目标媒体:RFID Journal、SecureIDNews、Event Manager Blog 类

## D. 展会与实体(按日程)

- 参展/赞助后确认 exhibitor 名录页有链接(RFID Journal LIVE、ISE、
  Canton Fair 线上名录等)

## 周记模板

```
W__:  目标[目录/客座/PR] | 动作 | 状态(待回复/已上线 URL) | 获得链接?
```

## 红线

- 不买链接、不进链接农场、不做全站sitewide交换 —— 2024 后的谷歌反垃圾
  对制造商站点尤其敏感,一次失误可让前面的内容投入清零。
- 锚文本自然分布:品牌名 > 裸URL > 主题词,精确匹配锚文本占比 <30%。
