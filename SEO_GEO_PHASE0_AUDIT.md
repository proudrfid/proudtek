## Tech Stack & Config Overview

- **Framework:** Astro 6.0.4, static SSG (`output: "static"`)
- **Content source:** WordPress snapshot fetched via `scripts/fetch-proudtek.mjs` into `src/data/site-data.json` (1,595 WP pages), then merged with synthetic catalog, editorial, and utility pages at build time
- **Layout:** Single `SnapshotLayout.astro` layout; single `buildPageSeo()` function in `src/lib/seo.ts` controls all `<head>` output (title, description, canonical, robots, OG, Twitter, JSON-LD)
- **Routing:** `index.astro` (homepage) + `[...slug].astro` (catch-all); low-value routes filtered out via `LOW_VALUE_ROUTE_PREFIXES`
- **`site` field:** Configured (`https://proudtek.com`)
- **`trailingSlash`:** `"always"` (good)
- **`compressHTML`:** Not enabled
- **`@astrojs/sitemap`:** Not used; custom sitemap generation in `seo-feeds.ts`
- **Astro `<Image>`:** Not used (all images are `<img>` from WP snapshot HTML)
- **`client:*` directives:** None found (fully static, no islands)
- **Build output:** `dist-restored/` directory

## SEO Infrastructure (Already In Place)

- **robots.txt:** Generated programmatically; disallows non-English locale prefixes; references sitemap.xml and image-sitemap.xml
- **Sitemaps:** Custom XML sitemap + image sitemap generated by `seo-feeds.ts`
- **Canonical URLs:** Set per-page; legacy redirect overrides in `route-overrides.ts` + `_redirects` (301s)
- **Meta tags:** title, description, robots (index/noindex), OG full suite, Twitter cards
- **JSON-LD:** Rich structured data -- Organization, WebSite, WebPage, BreadcrumbList, FAQ, Product schemas built in `buildJsonLd()`
- **GEO feeds:** `llms.txt`, `llms-full.txt`, `site-index.json`, per-page `/machine/...json` and `/machine/...txt` mirrors
- **hreflang:** Stripped at build time (English-only site, TranslatePress removed)
- **Conversion system:** CTA injection for product, article, and contact pages via `conversion.ts`
- **Analytics:** GA4 (G-30013548) inline in layout

## Top 10 Issues (by impact, descending)

1. **No `compressHTML` in Astro config** -- HTML output is unminified, increasing TTFB and transfer size across all 373 pages.

2. **No Astro `<Image>` optimization** -- All images are raw `<img>` tags from WP snapshots. No WebP/AVIF conversion, no width/height attributes enforcement, no lazy loading control. This impacts LCP and CLS.

3. **No `@astrojs/sitemap` integration** -- Custom sitemap works but misses Astro's automatic route discovery and `lastmod` precision. The custom `getLastModified()` falls back to `generatedAt` for non-blog pages (imprecise).

4. **GA4 script loaded synchronously in `<head>`** -- The gtag inline script blocks rendering. Should be deferred or loaded via Partytown.

5. **No hreflang x-default tag** -- hreflang tags are stripped but no `x-default` is declared to signal this is the canonical English version to search engines.

6. **Missing `<link rel="alternate" hreflang="en">` self-referencing tag** -- Best practice for English-only sites targeting global audience.

7. **No preconnect/preload hints** -- No resource hints for external origins (Google Analytics, image CDN). Impacts FCP.

8. **Blog content is thin** -- Only ~5 date-based articles from WP. The content hub strategy relies heavily on synthetic editorial pages but the blog index itself is sparse.

9. **No Web Vitals / performance budget** -- No Core Web Vitals monitoring beyond GA4. No performance budget in build pipeline.

10. **`case-studies/` section is empty** -- Only an index page exists with no actual case study content. This is a wasted crawl signal and potential trust-builder for B2B buyers.

## Phase Strategy Preview

| Phase 3 | Content & Schema | Expand blog content, populate case studies, enhance FAQ schema coverage, add Review/AggregateRating where applicable |
| Phase 4 | GEO Enhancement | Expand llms.txt coverage, validate machine-readable mirrors, test AI citation paths |
