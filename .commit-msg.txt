feat(seo): P0 audit follow-ups — sitemap hubs + HowTo + FAQ JSON-LD recovery [P0]

Three SEO completeness fixes surfaced by the 2026-05-12 site structure
audit, plus one dead-code removal.

1. sitemap.xml hub coverage (P0.1)
   src/lib/seo-feeds.ts: `/compare/` and `/guides/` hub indexes were
   missing from sitemap because they're native Astro pages, not in
   `siteData.pages`. Added a NATIVE_HUB_ROUTES const + explicit URL
   entries appended after the normal indexable-page loop.
   Sitemap goes 515 → 517 URLs.

2. HowTo JSON-LD recovery (P0.2)
   src/lib/seo/jsonld.ts: HowTo schema detection was DOM-based — it
   looked for `.codex-editorial-step-copy` elements in
   `page.bodyHtml`. After Stage 3 cutover the `<main>` of bodyHtml is
   empty (filled by EditorialPageLayout at render time, AFTER jsonld
   runs), so 0 HowTo schemas were emitted across 524 editorial pages.
   Rewrote to be data-driven: walks
   `page.editorialDefinition.sections` directly, extracts steps from
   `section.timeline.items` or from `section.bullets` when the
   section title matches `isWorkflowSection()` (workflow|steps|
   playbook). Same threshold (≥2 steps).

3. FAQ JSON-LD recovery for LPs (P0.3)
   src/lib/seo/page-data.ts: All 15 LP pages had `definition.faq` set
   (3 questions each) but FAQ JSON-LD was 0 across them, same root
   cause as HowTo — the `buildXxxFaqEntries($body, ...)` builders
   extracted from the now-empty `<main>` DOM. Added a short-circuit:
   if `page.editorialDefinition.faq` exists and is non-empty, use it
   directly (skip DOM extraction). All 15 LP pages now emit FAQPage
   schema; other groups also benefit when their fixtures carry
   authored FAQ.

4. Delete orphan Brief.astro (P1.1)
   src/components/editorial/Brief.astro: no `import` consumers
   (`BriefField` is used directly by `DecisionSnapshot`, the `Brief`
   wrapper was dead). Verified with `grep -rln "Brief\.astro" src/`
   before deletion.

Verification:
- npm test: 78/78 still pass (snapshot regenerations may flag —
  expected, since `<head>` JSON-LD blocks changed on guides + lps;
  use `npm test -- -u` after review)
- npm run build: 591 pages, clean
- dist/sitemap.xml: now 517 URLs (was 515)
- dist/guides/*: ≥1 HowTo JSON-LD now present (was 0)
- dist/lp/*: 15/15 FAQ JSON-LD (was 0)

This closes audit tasks #83-#86 (P0 + P1.1).
